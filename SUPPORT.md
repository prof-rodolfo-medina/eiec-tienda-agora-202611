# Canal oficial y contacto

Este repositorio es **material complementario** del curso *Entornos de Integración y Entrega Continua* (UNIR). No es un canal de comunicación.

| Para… | Usa |
|---|---|
| Consultar fechas, avisos y calificaciones | **Aula virtual** (las fechas del aula siempre prevalecen) |
| Entregar actividades | **Aula virtual** |
| Hacer una pregunta al profesor | Foro **"Pregúntale a tu profesor"** del aula virtual |
| Reportar un error en este repositorio | Foro **"Pregúntale a tu profesor"** (indica archivo, qué esperabas y qué pasó) |
| Resolver dudas en vivo | Clases síncronas por Zoom (enlace en el aula) |

- Este repositorio no tiene *issues* ni *discussions* abiertos al público y no publica correos de contacto.
- No envíes pull requests a este repositorio: tu trabajo vive en **tu fork** (los PR van de tus ramas a tu propio `main`).
- Si una fecha o instrucción de este repositorio no coincide con el aula, **vale el aula**.
