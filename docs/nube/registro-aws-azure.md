# Registro para uso de AWS y Microsoft Azure

> ## 🎓 Tienes acceso gratuito a la nube como estudiante de UNIR
>
> Por ser estudiante, **tienes derecho a usar Microsoft Azure y Amazon Web Services sin hacer pagos personales y sin tarjeta bancaria**. Mucha gente no lo sabe y deja pasar este beneficio.
>
> En este curso lo usaremos para desplegar Tienda Ágora en la nube real (semanas 7 y 8), pero el beneficio es tuyo: sirve para cualquier actividad académica y para practicar por tu cuenta.
>
> **La única condición:** regístrate con tu correo institucional **@comunidadunir.net**. Si usas un correo personal, no obtendrás el beneficio y podrían pedirte una tarjeta.
>
> **Hazlo en la semana 1**: la activación puede tardar y conviene tenerla lista antes de necesitarla.

Se cuentan con opciones para que los estudiantes puedan trabajar tanto en Microsoft Azure como en AWS sin que tengan que hacer pagos personales. Lo importante es que se registren con su correo institucional de **comunidadunir.net**.

## 1. Acceso a Microsoft Azure

El acceso se realiza directamente a través del programa **Azure for Students**, en el siguiente enlace:

- Azure for Students: <https://azure.microsoft.com/es-es/free/students/>

Los estudiantes deben:

- Ingresar al enlace Azure for Students.
- Registrarse con su correo de **comunidadunir.net**.

De esta forma se obtiene el crédito gratuito de estudiante y pueden utilizar la plataforma para las actividades académicas sin necesidad de tarjeta bancaria.

## 2. Acceso a AWS (Amazon Web Services)

Para AWS, el acceso es mediante **AWS Educate**, utilizando igualmente su correo institucional:

- AWS Educate: <https://aws.amazon.com/es/education/awseducate/>

Los estudiantes deben:

- Entrar al enlace de AWS Educate.
- Registrarse con su correo de **comunidadunir.net** para evitar cualquier cargo.
